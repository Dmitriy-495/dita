# DITA 0.1.0 — Iteration 001

## Тема

Минимальное типизированное основание Meta-Layer: `Catalog`.

## Решение

На первом шаге DITA получает отдельное типизированное представление мета-описания справочника:

```text
Catalog
├── id
├── name
└── prefix
```

Это соответствует ТЗ DITA 0.1.0. `Catalog` описывает структуру прикладного справочника, но ещё не является runtime-данными этого справочника.

## Граница шага

Этот шаг намеренно не включает PostgreSQL, HTTP API, Runtime и динамические реквизиты.

Причина: сначала необходимо проверить минимальную модель Meta-Layer, не создавая преждевременную универсальную инфраструктуру.

## Проверка

Для модели добавлена unit-проверка обязательных свойств `name` и `prefix`.

## Результат

Следующий архитектурный вопрос — способ хранения Meta-Layer в PostgreSQL. Он будет рассмотрен отдельной итерацией после проверки текущего основания.
